# Calendar RAG Assistant

עוזר שאלות ותשובות בעברית על אירועים בלוח עברי. זהו פרויקט Python עם ממשק טרמינל, המדגים תהליך RAG: שליפת אירועים מתוך אינדקס, העברת ההקשר ל־LLM, ניסוח תשובה והצגת המקורות שתומכים בה.

מקור הנתונים הוא [data/events.json](data/events.json), המכיל 40 אירועים. הנתונים כוללים ימי הולדת, ימי נישואין, ימי זיכרון, הערות ואירועים אחרים בלוחות משפחה, חברות, עבודה ולימודים. אין בקובץ שדה שנה; המערכת אינה מחשבת גיל או ממירה תאריכים ללוח לועזי.

## מה המערכת עושה

- עונה על שאלות נקודתיות ומעדיפה התאמה מדויקת לשם האירוע ולסוגו.
- מחזירה רשימות מלאות באמצעות סינון metadata לפי חודש, סוג, לוח או תאריך מזוהה.
- סופרת אירועים ייחודיים לאחר שליפה מלאה ומעבירה את המספר למודל לניסוח.
- מבקשת הבהרה כשיש כמה שמות מתאימים, במקום לבחור אדם או לוח ללא בסיס.
- מציגה מקורות שהמודל ציין ושמזהיהם קיימים בתוצאות השליפה.
- מחזירה תשובה שאין מידע מתאים כאשר לא נמצאה התאמה.

גם במסלול של התאמה מדויקת או רשימה מסוננת, התשובה עוברת דרך ה־LLM. אין מסלול המנסח תשובה סופית ישירות מה־JSON.

## טכנולוגיות והגדרות קיימות

| רכיב | המימוש בפרויקט |
|---|---|
| שפה וסביבת הפיתוח | Python 3.13.13, סביבת `.venv`, Windows/PowerShell |
| מסגרת RAG | LlamaIndex |
| LLM | `GoogleGenAI`, מודל `gemini-3.5-flash-lite` |
| Thinking | `minimal` |
| Embeddings | `GoogleGenAIEmbedding`, מודל `gemini-embedding-001` |
| אינדקס | `VectorStoreIndex` בזיכרון |
| Chunking | `SentenceSplitter(chunk_size=1024, chunk_overlap=0)` |
| שליפה סמנטית למועמדים | `similarity_top_k=3` |
| ניסוח תשובה | `RetrieverQueryEngine`, מצב `compact`, פלט מובנה `GroundedAnswer` |
| הגדרות סביבה | `python-dotenv` |

ארבע החבילות המוצהרות ב־[requirements.txt](requirements.txt) הן:

```text
llama-index
llama-index-llms-google-genai
llama-index-embeddings-google-genai
python-dotenv
```

ספריות נוספות שהקוד משתמש בהן, כגון `httpx` ו־Pydantic, מותקנות כתלויות של החבילות האלה. הפרויקט אינו משתמש בחבילה הישנה `llama-index-llms-gemini`.

## הרחבת בונוס — Metadata Filtering

`similarity_top_k=3` משמש לשליפה סמנטית של מועמדים בשאלות נקודתיות. הוא אינו מגבלה על רשימות מלאות: בבקשה רחבה המערכת משתמשת ב־Metadata Filtering ומאפשרת להחזיר עד כל ה־nodes באינדקס.

המסננים מבוססים על `hebrewMonth` (חודש), `hebrewDay` (יום), `type` (סוג אירוע) ו־`calendarName` (לוח). שילוב מסננים מאפשר, למשל, לשלוף את כל ימי ההולדת בחשוון בלוח משפחה, או רק את אירועי כ״ז בחשוון. כך מסנן מדויק מצמצם אירועים לא מתאימים, ותקרת השליפה הרחבה מונעת חיתוך רשימה לשלושה מועמדים. אחרי השליפה האירועים נשלחים ל־LLM לניסוח תשובה ולהצגת מקורות.

הרחבה זו כבר קיימת בקוד; לא שונתה במסגרת ההכנה להגשה. היא אינה מבטיחה שכל ניסוח יזוהה: התקלה „כמה הערות יש בכסלו?” ומגבלת האימות ביום ללא חודש עדיין פתוחות ומתועדות.
## התקנה

גרסת Python שאומתה בפועל ב־`.venv` היא **3.13.13**. יש לפתוח PowerShell בתיקיית הפרויקט. בהתקנה חדשה משתמשים ב־launcher של Python 3.13:

```powershell
py -3.13 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

אם סביבת `.venv` של הפרויקט כבר קיימת ומוכנה, אין צורך ליצור אותה מחדש. הפקודות כאן הן הוראות התקנה; לא בוצעה התקנה נוספת במסגרת כתיבת מסמכי ההגשה.

## הגדרת GOOGLE_API_KEY

צרו או ערכו קובץ בשם `.env` בשורש הפרויקט, באותה תיקייה של `main.py`, והגדירו בו:

```dotenv
GOOGLE_API_KEY=YOUR_GOOGLE_API_KEY
```

`YOUR_GOOGLE_API_KEY` הוא מציין מקום בלבד. יש להזין מקומית מפתח Google API בעל גישה למודלים המוגדרים בקוד. ניתן להיעזר בתבנית `.env.example`.

הקוד טוען את `.env` משורש הפרויקט לפי מיקום `main.py`. אין צורך לשים את המפתח בתיקיות `data` או `.venv/Scripts`. אין לצרף את המפתח למסמכי ההגשה. `.gitignore` כולל את `.env`, סביבת `.venv` וקובצי cache של Python.

## הרצה

מתוך תיקיית הפרויקט:

```powershell
.\.venv\Scripts\python.exe main.py
```

בתחילת ההרצה נטענים האירועים ונבנה אינדקס מול שירות ה־embeddings של Google. לאחר מכן מופיעה לולאת שאלות בעברית. לדוגמה:

```text
מה יש בכ״ז חשוון?
כמה אירועים יש בחשוון?
באיזה לוח נמצא יוסף?
```

לסיום כתבו `יציאה`, `exit` או `quit`. כאשר חסר מפתח, התוכנית מסבירה כיצד להגדיר אותו ונעצרת.

## תקלות ומגבלות

- נדרש חיבור לרשת ומכסה זמינה ב־Google. בניית האינדקס מתבצעת מחדש בכל הפעלה; אין כרגע אינדקס שמור על הדיסק.
- ב־504 או בשגיאות רשת זמניות המוגדרות בקוד, יש ניסיון חוזר אחד בלבד לשאלה. המכסה אינה נעקפת באמצעות תשובה חלופית.
- במקרה של כשל בבניית האינדקס מודפסים סוג השגיאה, קוד אם קיים וההודעה, תוך הסתרת המפתח.
- יום ללא חודש נתמך חלקית בצורות מפורשות כגון `כ״ז`. T07 הצליחה בהרצה מתועדת, אך נכשלה בבדיקה מאוחרת בשל אימות מחמיר, אף שבמאגר ארבע התאמות. אין להציג בעיה זו כפתורה במלואה.
- בשאלה „כמה הערות יש בכסלו?” דווחו 3 אירועים במקום 4, ללא „טיפול שיניים” מלוח משפחה. סיבת התקלה טרם אומתה והיא נותרה פתוחה.
- `permission` נשמר כמידע על האירוע; אין בפרויקט שכבת משתמשים או אכיפת הרשאות.
- אין כרגע React, שרת Node או API. זהו יישום טרמינל בלבד.
